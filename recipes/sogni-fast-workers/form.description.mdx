Deploy a Sogni Comfy or Stable Diffusion worker on SaladCloud.

The Comfy Worker replaces the retired FLUX Worker and is optimized for inference with the latest open-weight image and
video models on the Sogni network. The Stable Diffusion Worker remains available for Stable Diffusion models and
ControlNet workflows.

You will need a Sogni API key and a unique Fast Worker NFT Token ID. Deploy one replica per NFT Token ID.
