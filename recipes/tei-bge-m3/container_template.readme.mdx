# TEI BGE-M3 Embeddings

Serve `BAAI/bge-m3` with Hugging Face Text Embeddings Inference for RAG, semantic search, document retrieval, and similarity search.

## Model

- **Model ID**: `BAAI/bge-m3`
- **Embedding size**: 1024 dimensions
- **Maximum sequence length**: 8192 tokens
- **Strengths**: multilingual retrieval, long document retrieval, dense semantic embeddings, and similarity search

BGE-M3 is designed around multi-linguality, multi-functionality, and multi-granularity. In practice, this recipe gives you the dense embedding endpoint that most vector databases and RAG frameworks use.

## Deployment Notes

- Startup can take several minutes because `BAAI/bge-m3` is downloaded from Hugging Face at container startup.
- The container image is `ghcr.io/huggingface/text-embeddings-inference:89-1.9`.
- The TEI command is equivalent to `text-embeddings-router --model-id BAAI/bge-m3 --port 3000`.
- The container listens on port `3000` and exposes TEI's `/embed`, `/v1/embeddings`, `/similarity`, `/info`, `/health`, and `/docs` HTTP routes.
- The model's long context is useful for document retrieval, but very long batches use more VRAM. Tune `MAX_BATCH_TOKENS` and `MAX_CLIENT_BATCH_SIZE` in Advanced Configuration after load testing.
